Head-Gesture Game Jam · MIC Development Department, VIT Chennai

Your game is built. Now get it demo-ready.

At the demo, a station with a webcam reads the player's head movements and presses your game's keys (arrows, Z and Space) over the network. A small script on your laptop, the listener, receives those key presses. These steps take about 10 minutes.

Freeze your game

Build ends at 12:30 PM

  1. Save everything, and commit it if you use git.
  2. Start the game the same way you will at the demo (the command in your README, or open the HTML file) and play one round with the keyboard: arrows, Z, Space.
  3. Check that holding an arrow keeps moving and releasing stops, and that Z starts and restarts the game.
  4. Close apps you don't need (especially anything that shows pop-ups or notifications), and plug in your charger.

Troubleshooting
Still stuck? Ask a volunteer at the desk

    
The listener shows KEY lines, but my game doesn't react
      
    
        
  • Click inside your game window; keys only go to the window in front.
    • 
        
  • macOS: allow your terminal under Privacy & Security > Accessibility, then quit and reopen it.
    • 
        
  • Windows: if your game or engine runs as Administrator, run the terminal as Administrator too.
    • 
        
  • Check your game reads held keys every frame and doesn't only wait for key-repeat.
    • 
      

    
"python" / "py" is not recognized
      
Python isn't installed or isn't on PATH. Reinstall from python.org and tick "Add python.exe to
        PATH" (Windows). On macOS/Linux use python3.

    
ModuleNotFoundError: No module named 'websockets' / 'pynput'
      
The install step didn't run in this terminal. macOS/Linux: run
        source .venv/bin/activate first (prompt shows (.venv)), then
        pip install -r requirements-listener.txt. The listener prints the exact command to run.

    
macOS: pip fails while building "pyobjc-core"
      
Download the latest files from step 2 (the requirements file pins a version that works on
        macOS's built-in Python 3.9), or install Python 3.12+ from python.org and make a new .venv.

    
"the relay rejected the token"
      
The token is wrong. Check it for typos in the box at the top of this page.

    
"another laptop connected with this team ID"
      
Two laptops used the same team number. Only one listener per team: run it on the laptop that
        has the game.

    
Stuck on "Reconnecting…"
      
Check your internet connection. The server can take up to a minute to wake up. If the organizers
        switch to a backup server they'll give you a new address starting with ws://; use it
        in place of the one in the commands.

    
Antivirus warning or the script gets blocked
      
The listener is a plain, readable Python file that simulates key presses, which some antivirus
        tools flag. Allow it or add an exception for the folder.
